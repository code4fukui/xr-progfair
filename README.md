# xr-progfair
日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A project with 3D models and a game related to the PCN Kids Programmers Fair 2025.

## Demo
The project is hosted at https://code4fukui.github.io/xr-progfair/

## Features
- 3D models of the "Zero-Sen" fighter plane and "Koku 350K" snack available in USDZ and GLB formats
- A simple 3D game where you control the Zero-Sen plane and avoid the Koku 350K snacks

## Usage
The project files can be accessed and used from the GitHub repository at https://github.com/code4fukui/xr-progfair
