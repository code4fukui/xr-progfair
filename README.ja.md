# xr-progfair
日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

2025年PCN Kids Programmers Fairに関連する3Dモデルとゲームのプロジェクトです。

## デモ
このプロジェクトは https://code4fukui.github.io/xr-progfair/ でホストされています。

## 機能
- "ゼロ戦"戦闘機と "コク350K" スナックの3Dモデルが USDZ形式とGLB形式で利用可能です
- ゼロ戦機を操作してコク350Kスナックを避ける簡単な3Dゲームがあります

## 使用法
プロジェクトファイルは、https://github.com/code4fukui/xr-progfair の GitHub リポジトリからアクセスし、使用できます。
